# NayePankh Foundation Volunteer Registration System

## Project Overview
This project is a web-based Volunteer Registration and Management System developed for NayePankh Foundation. It allows volunteers to register, view events, and participate in activities, while administrators can manage volunteers and events through a dedicated dashboard.

## Features
- Volunteer Registration
- Volunteer Login
- Admin Login
- Admin Dashboard
- Event Management
- Volunteer Management
- Firebase Authentication
- Firestore Database Integration
- Responsive User Interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Cloud Firestore

## Setup Instructions

1. Clone the repository
   git clone <repository-url>

2. Open the project folder

3. Configure Firebase:
   - Create a Firebase project
   - Enable Authentication
   - Create Firestore Database
   - Add your Firebase configuration in firebase-config.js

4. Run the project using Live Server or any local web server.
